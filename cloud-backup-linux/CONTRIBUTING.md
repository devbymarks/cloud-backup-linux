# Contribuindo

Contribuições são bem-vindas.

1. Crie um fork do projeto.
2. Crie uma branch: `git checkout -b feature/minha-melhoria`.
3. Faça alterações pequenas e documentadas.
4. Execute `bash -n` nos scripts modificados e, se disponível, `shellcheck`.
5. Não inclua credenciais, IPs de produção, nomes de clientes ou chaves SSH.
6. Abra um Pull Request descrevendo o problema e a solução.

## Padrão de commits

Exemplos:

```text
feat: add checksum validation
fix: handle missing remote directory
security: restrict backup file permissions
docs: improve Informix setup guide
```
